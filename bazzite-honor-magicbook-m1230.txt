ШАГ 5. ПРОВЕРЯЕМ ACPI I2C_DEVT. ЭТО ОБЯЗАТЕЛЬНЫЙ SAFETY CHECK
======================================================================

Мы НЕ копируем AML вслепую.

Остаёмся здесь:

cd /var/opt/honor-magicbook-linux

Вставь блок:

LIVE=""

for f in /sys/firmware/acpi/tables/SSDT*; do
    OEM=$(sudo dd if="$f" bs=1 skip=16 count=8 status=none 2>/dev/null | tr -d '\0 ')

    if [[ "$OEM" == "I2C_DEVT" ]]; then
        LIVE="$f"
        break
    fi
done

if [[ -z "$LIVE" ]]; then
    echo "STOP: I2C_DEVT не найдена. НЕ продолжай со следующим шагом."
else
    LIVE_MD5=$(sudo md5sum "$LIVE" | awk '{print $1}')
    REF_MD5=$(md5sum dump/acpi/zqc-p/SSDT27_orig.aml | awk '{print $1}')

    echo "LIVE TABLE: $LIVE"
    echo "LIVE MD5 : $LIVE_MD5"
    echo "REPO MD5 : $REF_MD5"

    if [[ "$LIVE_MD5" == "$REF_MD5" ]]; then
        echo "OK: заводская I2C_DEVT полностью совпадает с reference."
    else
        echo "STOP: таблицы отличаются. AML НЕ устанавливаем и дальше НЕ продолжай."
    fi
fi

Только если в конце было OK — продолжаем.

ШАГ 13. ПРОВЕРЯЕМ DSC В ТЕКУЩЕМ OGC KERNEL
======================================================================

На текущем Bazzite OGC kernel CDCLK PTL fix уже присутствует.
Отдельный patch/cdclk-ptl НЕ запускаем.

HONOR edp-dsc installer тоже НЕ запускаем.
В OGC kernel есть writable debugfs switch для force DSC.

Сначала убеждаемся, что debugfs доступен:

sudo mountpoint -q /sys/kernel/debug || sudo mount -t debugfs debugfs /sys/kernel/debug

Находим DSC file:

DSC_FILE=$(sudo find /sys/kernel/debug/dri \
  -path '*/eDP-*/i915_dsc_fec_support' \
  -print -quit)

echo "$DSC_FILE"

Он НЕ должен быть пустым.

Смотрим:

sudo cat "$DSC_FILE"

Нужно увидеть как минимум:

DSC_Sink_Support: yes

До force обычно будет:

DSC_Enabled: no
Force_DSC_Enable: no

Если DSC_Sink_Support НЕ yes — СТОП, force не делаем.

ШАГ 14. ДЕЛАЕМ DSC АВТОМАТИЧЕСКИМ ПРИ КАЖДОМ BOOT
======================================================================

Создаём helper:

sudo install -d -m755 /usr/local/lib/honor

sudo tee /usr/local/lib/honor/force-dsc.sh >/dev/null <<'EOF'
#!/usr/bin/bash
set -euo pipefail

mountpoint -q /sys/kernel/debug || mount -t debugfs debugfs /sys/kernel/debug

for _ in $(seq 1 300); do
    DSC_FILE=$(find /sys/kernel/debug/dri \
      -path '*/eDP-*/i915_dsc_fec_support' \
      -print -quit 2>/dev/null || true)

    if [[ -n "$DSC_FILE" && -w "$DSC_FILE" ]]; then
        if ! grep -q 'DSC_Sink_Support: yes' "$DSC_FILE"; then
            echo "HONOR: panel does not report DSC support" >&2
            exit 1
        fi

        echo 1 > "$DSC_FILE"
        exit 0
    fi

    sleep 0.05
done

echo "HONOR: i915_dsc_fec_support not found" >&2
exit 1
EOF

sudo chmod 755 /usr/local/lib/honor/force-dsc.sh

Создаём service:

sudo tee /etc/systemd/system/honor-force-dsc.service >/dev/null <<'EOF'
[Unit]
Description=Force DSC on HONOR ZQC-P internal eDP panel
After=systemd-modules-load.service
Before=display-manager.service

[Service]
Type=oneshot
ExecStart=/usr/local/lib/honor/force-dsc.sh
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF

Включаем:

sudo systemctl daemon-reload
sudo systemctl enable honor-force-dsc.service

Пока reboot не делаем — сначала доделаем update protection.

ШАГ 15. ДЕЛАЕМ БЕЗОПАСНОЕ ОБНОВЛЕНИЕ HONOR SOURCE TREE
======================================================================

Сам source tree НЕ должен самовольно переустанавливать тебе фиксы.
Он нужен только если когда-нибудь вручную захочешь обновить upstream.

НИКОГДА не делай в нём обычный git pull.

Создаём безопасный updater:

sudo tee /usr/local/bin/honor-source-update >/dev/null <<'EOF'
#!/usr/bin/bash
set -euo pipefail

REPO=/var/opt/honor-magicbook-linux
cd "$REPO"

if [[ "$(git branch --show-current)" != "m1230-bazzite" ]]; then
    echo "STOP: expected branch m1230-bazzite" >&2
    exit 1
fi

if [[ -n "$(git status --porcelain)" ]]; then
    echo "STOP: working tree dirty. Ничего не обновляю." >&2
    git status --short
    exit 1
fi

git branch -f honor-last-good HEAD
git fetch --prune origin

if git rebase origin/main; then
    echo
    echo "HONOR source tree updated."
    echo "ВАЖНО: установленные системные фиксы автоматически НЕ менялись."
    echo "Новый installer запускай только вручную после проверки."
else
    echo
    echo "Upstream конфликтует с нашим M1230 commit."
    echo "Отменяю rebase и сохраняю старое рабочее состояние."
    git rebase --abort || true
    exit 1
fi
EOF

sudo chmod 755 /usr/local/bin/honor-source-update

Проверка:

command -v honor-source-update

В БУДУЩЕМ исходники обновлять только так:

honor-source-update

Он ничего не патчит.
Он только проверяет, не отъехали ли наши настройки после нового Bazzite deployment.

sudo tee /usr/local/lib/honor/health-check.sh >/dev/null <<'EOF'
#!/usr/bin/bash
set -u

LOG=/var/lib/honor/health-last.txt
mkdir -p /var/lib/honor
exec > >(tee "$LOG") 2>&1

FAIL=0

ok()   { echo "[ OK ] $*"; }
warn() { echo "[WARN] $*"; }
bad()  { echo "[FAIL] $*"; FAIL=1; }

echo "HONOR ZQC-P M1230 health check"
echo "kernel: $(uname -r)"
echo

KLOG="$(journalctl -k -b --no-pager 2>/dev/null || true)"

if grep -q 'AE_AML_INTERNAL' <<<"$KLOG"; then
    bad "ACPI: AE_AML_INTERNAL вернулся"
else
    ok "ACPI: нет AE_AML_INTERNAL"
fi

if ls /sys/bus/hid/devices/*2808:5662* >/dev/null 2>&1; then
    ok "touchscreen 2808:5662"
else
    bad "touchscreen 2808:5662 не найден"
fi

if compgen -G '/sys/bus/hid/devices/*27C6:0F9A*' >/dev/null || \
   compgen -G '/sys/bus/hid/devices/*27c6:0f9a*' >/dev/null; then
    ok "touchpad 27c6:0f9a"
else
    bad "touchpad 27c6:0f9a не найден"
fi

PSR="$(cat /sys/module/xe/parameters/enable_psr 2>/dev/null || true)"

if [[ "$PSR" == "1" ]]; then
    ok "xe.enable_psr=1"
else
    bad "xe.enable_psr=${PSR:-missing}"
fi

if command -v udev-hid-bpf >/dev/null 2>&1; then
    if [[ -f /etc/udev-hid-bpf/honor-ftsc1000-micmute.bpf.o ]]; then
        ok "micmute HID-BPF object installed"
    else
        bad "micmute HID-BPF object отсутствует"
    fi

    if [[ -f /etc/udev-hid-bpf/honor-tops0102-edge.bpf.o ]]; then
        ok "touchpad-edge HID-BPF object installed"
    else
        bad "touchpad-edge HID-BPF object отсутствует"
    fi

    if systemctl is-active --quiet honor-hid-bpf-reapply.service; then
        ok "micmute re-apply service active"
    else
        bad "micmute re-apply service not active"
    fi
else
    bad "udev-hid-bpf command отсутствует"
fi

PHANTOM="$(
    grep -l UNKNOWN /sys/class/input/input*/name 2>/dev/null |
    xargs -r grep -H 2808 2>/dev/null || true
)"

if [[ -z "$PHANTOM" ]]; then
    ok "phantom KEY_MICMUTE отсутствует"
else
    bad "phantom KEY_MICMUTE вернулся"
    echo "$PHANTOM"
fi

DSC_FILE="$(find /sys/kernel/debug/dri \
  -path '*/eDP-*/i915_dsc_fec_support' \
  -print -quit 2>/dev/null || true)"

if [[ -n "$DSC_FILE" ]]; then
    DSC="$(cat "$DSC_FILE" 2>/dev/null || true)"

    grep -q 'DSC_Sink_Support: yes' <<<"$DSC" \
        && ok "DSC sink supported" \
        || bad "DSC sink support отсутствует"

    grep -q 'Force_DSC_Enable: yes' <<<"$DSC" \
        && ok "DSC force enabled" \
        || bad "DSC force не включился"

    if grep -q 'DSC_Enabled: yes' <<<"$DSC"; then
        ok "DSC active"
    else
        warn "DSC force есть, но DSC сейчас не active; возможно, ещё не было нового modeset"
    fi
else
    bad "i915_dsc_fec_support не найден"
fi

DISPLAY_INFO="$(find /sys/kernel/debug/dri \
  -name i915_display_info \
  -print -quit 2>/dev/null || true)"

if [[ -n "$DISPLAY_INFO" ]]; then
    PIPE="$(grep -m1 -E 'pipe src=.*bpp=' "$DISPLAY_INFO" 2>/dev/null || true)"

    if grep -q 'bpp=30' <<<"$PIPE" && grep -q 'dither=no' <<<"$PIPE"; then
        ok "display: bpp=30, dither=no"
    elif [[ -n "$PIPE" ]]; then
        warn "display сейчас не bpp=30/dither=no: $PIPE"
    fi
fi

if [[ -d /opt/honor-libfprint-sdcp ]]; then
    ok "private SDCP libfprint directory exists"

    if ldconfig -p 2>/dev/null | grep -q '/opt/honor-libfprint-sdcp'; then
        ok "private SDCP libfprint есть в ld cache"
    else
        bad "private SDCP libfprint выпал из ld cache"
    fi
else
    bad "/opt/honor-libfprint-sdcp отсутствует"
fi

echo

if (( FAIL )); then
    echo "RESULT: FAIL"
    exit 1
fi

echo "RESULT: OK"
EOF

sudo chmod 755 /usr/local/lib/honor/health-check.sh

Создаём service:

[Service]

======================================================================
КАК ТЕПЕРЬ ОБНОВЛЯТЬ BAZZITE
======================================================================

Обычный Bazzite update делаешь ШТАТНО, как всегда.

После update:
1. перезагружаешься;
2. ждёшь примерно минуту;
3. выполняешь:

cat /var/lib/honor/health-last.txt

Если:

RESULT: OK

ничего делать не надо.

Почему наши вещи должны переживать Bazzite updates:
- ACPI AML находится в /etc;
- dracut config находится в /etc;
- rpm-ostree local initramfs включён постоянно;
- xe.enable_psr=1 хранится как karg;
- HID-BPF объекты живут в /etc/udev-hid-bpf;
- micmute имеет boot re-apply service;
- DSC имеет собственный systemd service;
- fingerprint SDCP library живёт в /opt;
- его ld.so config живёт в /etc;
- source tree живёт в /var/opt;
- мы НЕ подменяем kernel modules;
- мы НЕ собираем xe.ko под конкретную версию kernel.

Именно поэтому kernel update не должен заставлять нас пересобирать половину
ноутбука заново.


======================================================================
КАК ОБНОВЛЯТЬ САМ HONOR-РЕПОЗИТОРИЙ
======================================================================

НЕ:

cd /var/opt/honor-magicbook-linux
git pull

А только:

honor-source-update

Updater:
- откажется работать на грязном tree;
- сохранит старый HEAD как honor-last-good;
- fetch'нет upstream;
- попробует rebase нашего одного M1230 commit;
- при конфликте отменит rebase;
- НИЧЕГО автоматически не переустановит в системе.

Вернуться к последнему source state:

cd /var/opt/honor-magicbook-linux
git reset --hard honor-last-good

Это откатывает ТОЛЬКО исходники.
Уже установленные системные фиксы от этого сами не меняются.

ЕСЛИ НОВЫЙ BAZZITE UPDATE СЛОМАЛ ЗАГРУЗКУ

======================================================================
ЧТО МЫ СПЕЦИАЛЬНО НЕ СТАВИМ НА M1230
======================================================================

1. cdclk-ptl
Нужный Panther Lake CDCLK fix уже есть в текущем Bazzite OGC kernel.

2. patch/edp-dsc/install.sh
Не нужен: используем уже существующий writable DSC switch и не трогаем xe.ko.

3. sof-audio
Нужное refresh copier_data исправление уже есть в текущем OGC kernel.

4. i8042.dumbkbd=1
Не нужен на Linux 7.2+ и ломает нормальный Caps Lock LED.

5. oled-backlight
Не копируем floor с чужой панели. Его сначала надо отдельно измерить на M1230.

6. fan
Не копируем EC offsets M1010/M1050 без измерения M1230.

7. battery
Не копируем EC charge presets без проверки M1230.

8. hotkeys / hotkey-actions
Не копируем вслепую: камера у M1230 имеет USB ID 30c9:012c,
а у известных M1010/M1050 другой ID.

9. headset-mic
SSID 1ee7:209d известен, но отдельный kernel-module quirk ставим только если
реально окажется, что микрофон 3.5mm гарнитуры не работает.
